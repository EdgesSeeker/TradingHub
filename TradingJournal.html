📋 Schnellstart-Anleitung:

  • Favorit hinzufügen: Drücken Sie Ctrl + D im Browser
  • Desktop-Verknüpfung: Ziehen Sie diese Datei auf den Desktop
  • Taskleiste: Rechtsklick auf Browser-Tab → "An Taskleiste anheften"
  • Autostart: Fügen Sie diese Datei zum Windows-Autostart hinzu

💾 Daten-Sicherheit:

  • ✅ Alle Daten werden lokal in Ihrem Browser gespeichert
  • ✅ Keine Daten werden an externe Server gesendet
  • ✅ Daten bleiben auch nach Computer-Neustart erhalten
  • ⚠️ Daten gehen verloren, wenn Sie Browser-Daten löschen
