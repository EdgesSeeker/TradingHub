# 📱 Vollbildmodus für Trading Journal

## 🚀 Vollbildmodus aktivieren

### **Methode 1: Vollbildmodus-Button (Empfohlen)**
1. Öffnen Sie die Trading Journal App auf Ihrem Handy
2. Tippen Sie auf den **Vollbildmodus-Button** (⛶) in der oberen rechten Ecke
3. Die App wechselt automatisch in den Vollbildmodus
4. Zum Beenden: Tippen Sie erneut auf den Button (⊡)

### **Methode 2: Browser-Vollbildmodus**
1. Öffnen Sie die App im Browser
2. **Android (Chrome):**
   - Tippen Sie auf das Menü (3 Punkte)
   - Wählen Sie "Vollbildmodus" oder "Im Vollbild anzeigen"
3. **iPhone (Safari):**
   - Tippen Sie auf das Teilen-Symbol
   - Wählen Sie "Zum Home-Bildschirm hinzufügen"
   - Öffnen Sie die App vom Home-Bildschirm

### **Methode 3: PWA-Installation (Beste Erfahrung)**
1. Gehen Sie zu: `http://[Ihre-IP]:3000/pwa-install.html`
2. Folgen Sie den Installations-Anweisungen
3. Die App wird als native App installiert
4. Öffnen Sie die App vom Startbildschirm

## 🚨 Fehlerbehebung

### **Vollbildmodus funktioniert nicht:**
- Stellen Sie sicher, dass Sie die neueste Version verwenden
- Versuchen Sie, die Seite neu zu laden
- Verwenden Sie die PWA-Installation als Alternative

### **Market Monitor zeigt nicht richtig:**
- Die mobile Version wird automatisch auf Handys geladen
- Stellen Sie sicher, dass Sie die App im Vollbildmodus verwenden
- Versuchen Sie, die Seite neu zu laden

## 📞 Support

Bei Problemen:
1. Überprüfen Sie die Browser-Konsole auf Fehler
2. Stellen Sie sicher, dass JavaScript aktiviert ist
3. Versuchen Sie einen anderen Browser
4. Verwenden Sie die PWA-Installation
