📱 Installation auf deinem Gerät:

📱 Handy
💻 Desktop
Android (Chrome/Samsung Internet)
  1. Öffne die Trading Journal Website
  2. Tippe auf das Menü (3 Punkte oben rechts)
  3. Wähle "Zur Startseite hinzufügen" oder "App installieren"
  4. Bestätige die Installation
  5. Die App erscheint auf deinem Startbildschirm
iPhone/iPad (Safari)
  1. Öffne die Trading Journal Website in Safari
  2. Tippe auf das Teilen-Symbol (Quadrat mit Pfeil)
  3. Wähle "Zum Home-Bildschirm"
  4. Bestätige mit "Hinzufügen"
  5. Die App erscheint auf deinem Home-Bildschirm
Chrome/Edge (Windows/Mac/Linux)
  1. Öffne die Trading Journal Website
  2. Suche nach dem Installations-Symbol in der Adressleiste
  3. Klicke auf "Installieren" oder "App installieren"
  4. Bestätige die Installation
  5. Die App öffnet sich in einem eigenen Fenster
Firefox
  1. Öffne die Trading Journal Website
  2. Klicke auf das Menü (3 Striche oben rechts)
  3. Wähle "Diese Seite als App installieren"
  4. Bestätige die Installation
  5. Die App wird in deinen Anwendungen verfügbar
